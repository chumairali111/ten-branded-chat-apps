# Visual provenance

The files in docs/previews are code-rendered UI illustrations with fictional/demo conversations. They are NOT screenshots captured from a running Android device or Flutter build. Each image includes a visible UI PREVIEW / DEMO DATA label. They illustrate source-supported flows and branding; they do not prove functional tests, network reliability or exact on-device pixel layout. Do not remove the labels or describe them as captured device screenshots. Replace them with real captures when available.
